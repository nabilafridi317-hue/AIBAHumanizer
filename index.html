কীভাবে GitHub Pages-এ ফ্রিতে সাইট হোস্ট করবেন:

  1. GitHub Account তৈরি করুন: github.com-এ ফ্রি অ্যাকাউন্ট খুলুন।
  2. নতুন Repository তৈরি করুন: ডানপাশের "+" আইকন থেকে "New repository" ক্লিক করুন।
  3. Repository Name দিন: পছন্দমতো নাম দিয়ে (যেমন: ai-suite) Public রেখে তৈরি করুন।
  4. HTML ফাইল Upload করুন: কোডটি index.html নামে সেভ করে আপলোড করুন।
  5. Pages চালু করুন: Repository-র Settings -> Pages এ গিয়ে Branch main সিলেক্ট করে Save চাপুন।
